# 第一关：积水区 · 场景设计

**积水区是每一局的起点，也是零（本体）长大的地方。这一关要同时完成三件事：教会玩家基本操作和四大系统、讲清楚“底层被遗弃”的世界观、用排水王一战给出第一个情感落点。**

本文档供策划、美术、程序共同使用。玩法名词与《世界观与设定》的「玩法设计」一致，人物与《剧情与人物》一致。

## 一、概览

| 项目 | 设定 |
| --- | --- |
| 区域定位 | 第 1 区，每局必经，难度最低 |
| 时长 | 首次 8–12 分钟；熟练后 5–7 分钟 |
| 房间数 | 战斗房 5–6 间 + 奖励/事件房 1–2 间 + 商店 1 间 + Boss 1 间 |
| 核心动词 | **藏、引电**：利用黑暗躲避，把敌人引进积水再通电 |
| 教学目标 | 移动与闪移、换武器、骇入、积水导电、门上的奖励标识 |
| 主色 | 洋红 + 青，压暗的蓝黑底色 |
| 天气 | 持续大雨，雨量随剧情推进减少 |
| Boss | 「排水王」老汉克，迷彩旧军用机甲 |
| 关键记忆 | 小时候的零在雨里修收音机，第一次听到幽灵频道的声音 |

## 二、区域叙事

**玩家在这一关应该感受到：这里很穷、很湿、很危险，但有人在用自己的方式活着。**

### 三个区段

积水区分成三个视觉区段，房间按顺序从一个区段过渡到下一个，让玩家明显感觉到“越走越深”。

| 区段 | 位置 | 视觉 | 情绪 |
| --- | --- | --- | --- |
| A · 霓虹主街 | 第 1–2 间 | 餐馆、当铺、面馆的招牌，路灯光池，积水倒影 | 热闹但破旧，还有人气 |
| B · 后巷与高架桥下 | 第 3–5 间 | 垃圾箱、晾衣绳、漏电的电缆、高架桥的水泥柱 | 拥挤、压抑，光源变少 |
| C · 排水泵站 | 第 6 间到 Boss | 巨大的排水管道、生锈的泵机、混凝土水渠 | 工业、空旷、轰鸣 |

### 环境叙事

不用过场，靠场景里的东西讲故事：

- **墙上的涂鸦**：“排水费 = 保护费？”“汉克修好了 4 号泵”“无雨日 = 我们的末日”。前后矛盾，让玩家对排水王的印象一开始就是模糊的。
- **广播**：穹顶的宣传广播在街上循环播放“无雨日倒计时”和“免费永生”的广告。每个新局，倒计时的天数都会减少。
- **尸体身上的纸条**：比如“欠排水费三个月，汉克说下个月再说”。这暗示排水王并不像传说中那么凶。
- **居民**：主街的屋檐下有不参战的居民。开战时他们会躲进店里，打完后会探出头说一句话。

### 第一场战斗的理由：悬赏

**零刚走出诊所就被围住，因为她的脸值钱。穹顶集团在底层挂了悬赏：“活捉这张脸，换一台新排水泵。”**

- **谁在打她**：排水王手下的湿鞋帮。他们不恨零，甚至不知道她是谁。他们要的是那台泵：4 号泵快撑不住了，再坏一次，半条街都会被淹。
- **他们怎么知道她在这**：有人把诊所的位置卖给了穹顶。玩家此时不知道是谁，第三幕才揭晓是老鬼。
- **零的处境**：她刚醒，什么都不记得，不知道自己为什么被追。玩家和她一样带着疑问开打：“我做了什么？”
- **第一句钩子**：领头的刀手看清她的脸后愣了一下，说：“又是这张脸。上一个不是已经沉进港里了吗？”这句话暗示在她之前还有别的“她”。
- **和 Boss 战的呼应**：打到泵站，汉克亲口说出这笔交易。玩家这时才明白，第一场战斗里的敌人不是坏人，只是一群怕被淹的人。

**开场流程（约 40 秒）**

1. 零推开诊所的门，雨声变大。街对面屋檐下的居民迅速关上了窗。
2. 三个刀手从巷口走出来，手里拿着一张被雨打湿的悬赏单。
3. 刀手：“又是这张脸。上一个不是已经沉进港里了吗？”
4. 零：“……你们认错人了。”（停顿）“大概。”
5. 刀手：“活的值一台泵。别打坏脸。”战斗开始。
6. 打完后，零捡起悬赏单：上面是她的脸，名字一栏写着“资产 #47”。对讲机里娥姬沉默了两秒：“……先往东走。回来我再解释。”

### 战斗视角与场景构图

战斗采用和《哈迪斯》相同的**斜 45° 俯视构图**：场地是一块架在水面上的菱形平台，后方两面是建筑立面，前方两面敞开，边缘是排水管和护栏。镜头角度固定，跟随玩家，不旋转。

- 地面网格：一格 40×20 像素的菱形（2:1），内部分辨率 960×540。
- 第一小关「雨中主街」的场地为 20×14 格。
- 角色需要按斜向重新绘制朝向（建议 8 方向，至少 4 个斜向）。
- 第七节里的方格布局图是横平竖直时期的草图，表示的是元素的相对位置；实际摆放以场景地图为准。

**连续的世界：行进方向自下而上**

积水区不是一间间独立的房间，而是一张连在一起的地图。零从画面下方的回声诊所出发，一路向上走，镜头跟着她移动，场景之间没有读图切换。进入一个战斗区域时，出入口会被卷帘门或电网暂时封住，清完敌人后打开。

前三关的连接方式：

| 顺序 | 区域 | 怎么连到下一段 |
| --- | --- | --- |
| ① | 雨中主街（出生点，闪移教学） | 右上角的路口，沿上行街道往右上走 |
| — | 上行街道（公用电话亭、义体修理铺、纹身店） | 街道尽头是面馆门口的斑马线 |
| ② | 面馆门口（积水导电教学） | 左上角的拱门，拐进后巷往左上走 |
| ③ | 当铺后巷（暗区教学） | 巷子尽头的闸门，通往高架桥下 |

**每局随机：街区拼接**

世界由预先做好的“街区”拼成。每局开始时随机挑选街区并排好顺序，街区之间用固定规格的接口无缝衔接，所以每局的路线不同，但看起来始终是一座连续的城。

| 规则 | 内容 |
| --- | --- |
| 街区 | 一块手工设计的场地（如雨中主街、面馆门口、当铺后巷），自带建筑、道具、刷怪点和教学目标 |
| 接口 | 每个街区有一个入口和 1–2 个出口，统一为 3 格宽的栈桥口；出口朝右上或左上，保证总是往画面上方走 |
| 连接段 | 街区之间插入一小段架在桩子上的栈桥或巷子（如上行街道），电话亭、商人、事件都放在连接段里 |
| 一局的构成 | 固定开头（雨中主街）+ 随机 4–5 个街区 + 固定结尾（泵站前厅、4 号泵站） |
| 分叉 | 有两个出口的街区就是分叉点，两个出口上方显示不同的奖励标记 |
| 封门 | 进入街区后出入口被卷帘门或电网封住，清完敌人后打开 |
| 首次游玩 | 顺序固定：雨中主街 → 面馆门口 → 当铺后巷 → 高架桥下 → 泵站 |

建筑只放在可行走区域的后方两侧，前方两侧是排水管和护栏，这样近处的楼不会挡住人。

| 概念图里的东西 | 游戏里的做法 |

### 美术基调：贫民窟与荒败感

积水区是底层人住的地方，画面要让人一眼看出“这里被遗弃了很久，但还有人在硬撑着过日子”。

| 方面 | 做法 |
| --- | --- |
| 建筑 | 墙皮剥落、补过的砖、锈水痕、墙根的霉斑和裂缝；窗户多数是黑的，有的用木板封死，有的蒙着塑料布，亮着的窗装了防盗栏 |
| 加盖 | 屋顶上是各家自己搭的铁皮棚，用轮胎和砖头压着棚顶；墙上钉着铁皮补丁；到处是乱拉的电线 |
| 招牌 | 霓虹灯大多坏了一截，只有回声诊所的招牌是完整的 |
| 街面 | 帐篷和纸箱窝棚靠墙搭着，火桶是除了霓虹之外的主要光源；轮胎、油桶、垃圾堆、木板随处可见 |
| 地面 | 泥斑、坑洼积水、裂缝、褪色的黄色车道线；雨水汇进边缘的排水管，从出水口排到下层 |
| 公共设施 | 路灯三成是坏的，两成发暗；平台边缘是锈蚀的排水管和缺段的护栏，缺口用铁皮挡着 |
| 光 | 整体更暗。暖色来自火桶和少数亮着的窗，冷色来自坏掉的霓虹和带电的积水 |

## 三、路线结构

### 单局流程

```
 诊所 ──► [1 开场房] ──► [2 战斗] ──► [3 战斗] ─┬─► [4a 战斗] ─┐
                                                  └─► [4b 事件] ─┤
                                                                  ▼
 Boss ◄── [泵站前厅/商店] ◄── [6 战斗] ◄── [5 战斗或奖励] ◄──────┘
```

- 第 1 间固定为开场房；第 2、3 间从“主街”房间池抽取；第 4 间开始出现分叉，玩家在两扇门之间选择。
- 每间战斗房清完后，出口门上会显示下一间的奖励图标。分叉时，两扇门显示不同的奖励，让玩家自己权衡。
- 商店固定在 Boss 前一间，和“泵站前厅”合并。

### 房间类型与出现概率

| 房间类型 | 门上图标 | 这一关的出现次数 | 奖励 |
| --- | --- | --- | --- |
| 战斗房 · 协议 | AI 的霓虹色徽记 | 2–3 | 一个 AI 协议三选一 |
| 战斗房 · 武器 | 枪的剪影 | 1 | 一把武器（改良或精良） |
| 战斗房 · 信用点 | 硬币 | 0–1 | 信用点 |
| 义体诊所房 | 十字加齿轮 | 0–1 | 免费安装一件义体（三选一） |
| 事件房 | 问号 | 0–1 | 见第七节 |
| 宝箱房 | 箱子 | 0–1 | 精良以上武器，或者一件义体 |
| 商店 | 老鬼的全息脸 | 1（固定） | 购买武器、义体、回血 |
| Boss | 骷髅 | 1（固定） | Boss 专属武器或装甲，二选一 |

**首次游玩的固定路线**：第一次进入积水区时，路线和奖励是固定的，用来教学（见第五节）。从第二局开始才完全随机。

## 四、环境元素

**积水区所有的环境元素，都围绕“水”和“电”两个东西设计。规则对敌我一视同仁，所有危险都有预警。**

### 地形与道具

| 元素 | 图例 | 尺寸 | 规则 | 怎么利用 |
| --- | --- | --- | --- | --- |
| 积水 | `~` | 任意形状 | 平时无害，移速不变；被电击时整片带电 3 秒，每秒 12 伤害 + 麻痹 | 把敌人引进水里，再通电 |
| 漏电电缆 | `=` | 1×3 至 1×6 | 每 4 秒甩动一次，扫过 15 伤害；甩进积水时会让积水带电 | 打断电缆的支架，让它永远掉进水里，变成持续带电的死区 |
| 变电箱 | `B` | 2×2 | 可骇入（2 RAM）：房间内所有积水带电 5 秒；之后冒烟，本房间不能再用 | 一波敌人刚刷出、都站在水里时使用 |
| 霓虹招牌 | `N` | 1×2 至 3×2 | 6 点生命，可被打碎；打碎后周围半径 3.6 格变成暗区 | 站进暗区，敌人在 2.5 格外看不见你；从暗处攻击必定暴击 |
| 路灯 | `L` | 1×1 | 不可破坏，脚下形成光池 | 站在光池里会被所有敌人看见，是“危险区”的视觉提示 |
| 下水道井盖 | `O` | 1×1 | 交互：钻进去 2 秒无敌，从房间内另一个井盖钻出 | 被包围时脱身；少数井盖通往深网 |
| 废弃汽车 | `C` | 3×2 | 掩体，8 次攻击后起火，3 秒后爆炸（半径 2，30 伤害） | 把敌人引到车边，再打爆 |
| 雨棚 | `^` | 2×2 至 4×2 | 棚下不下雨，脚步声变小 | 纯氛围，同时提示玩家这里是安全角落 |
| 自动售货机 | `S` | 1×2 | 打碎后掉落 1–3 个电池（回复电量） | 电量不够时的补给 |
| 晾衣绳 | `-` | 横跨巷子 | 不挡子弹，会被子弹打断 | 纯氛围，打断时有布料飘落的反馈 |

### 预警规则

| 危险 | 预警方式 | 预警时长 |
| --- | --- | --- |

## 九、Boss 战：排水王

### 他是谁

**老汉克，58 岁，退伍机甲驾驶员。他开着旧军用机甲向居民收“排水费”，所有人都以为他是恶霸。其实他把收来的钱都用来修排水泵：公司二十年没修过积水区的泵，没有他，整个街区早就淹了。**

他和零打，是因为穹顶给他开了价：交出零，就给他一台新泵。

### 场地：4 号泵站

45×26 的大房间。中央是一条混凝土排水渠，渠里有积水。场地四角各有一台排水泵，泵是可以利用的场景机关。

```
#############################################
#[泵A].............................[泵B]....#
#...........................................#
#....##.......~~~~~~~~~~~~~~~~.......##.....#
#....##.......~~~~~~~~~~~~~~~~.......##.....#
P.............~~~~~~~~~~~~~~~~..............#
#.............~~~~~~~~~~~~~~~~..............#
#....##.......~~~~~~~~~~~~~~~~.......##.....#
#....##..............................##.....#
#..B......................................B.#
#[泵C].............................[泵D]....#
#############################################
```

- 中间的排水渠一开始只有浅水；进入第二阶段后，水位上涨，积水会漫到整个中场。
- 两个变电箱 `B` 在左右两侧，可以骇入，让积水带电。
- 四根水泥柱 `##` 是掩体，被机甲撞 3 次后倒塌。

### 第一阶段：机甲（生命 100% → 50%）

| 招式 | 预警 | 效果 | 应对 |
| --- | --- | --- | --- |
| 踩踏 | 机甲抬脚，地面出现红圈 | 圆形范围 25 伤害 | 闪移离开红圈 |
| 扫射 | 机甲转身，枪口发光 0.6 秒 | 扇形弹幕，持续 2 秒 | 躲到水泥柱后 |
| 冲撞 | 机甲后退半步，蒸汽喷出 | 直线冲锋，撞到柱子会晕 2 秒 | 引它撞柱子，然后输出 |
| 甩管 | 机甲举起手臂上的排水管 | 喷出高压水流，地上留下一条积水 | 积水可以拿来导电，反过来坑它 |

**弱点**：机甲背后的散热口。机甲撞柱子晕住时，从背后打伤害翻倍。

### 第二阶段：开闸（生命 50% → 0%）

汉克打开排水闸，喊：“你要拆我的泵，我就让你尝尝没有泵是什么滋味！”

- 水位上涨，中场全部变成积水。
- 汉克每次踩踏都会在积水里放电。
- 机甲脚下的两个变电箱亮起，可以骇入，反过来电汉克 3 秒（他站在水里）。
- 四台排水泵依次启动，各自喷出水流把玩家往场地中央推。打坏一台泵可以停掉它，但汉克会愣一下，说“那是 C 泵……”。

**节奏设计**：第二阶段的核心是“谁先利用好水”。玩家在水里会被电，但汉克也站在水里。骇入变电箱是最大的输出窗口。

### Boss 对白

| 时机 | 台词 |
| --- | --- |
| 开战 | “又一个想收我泵的。穹顶派你来的？……算了，谁派的都一样。” |
| 进入第二阶段 | “你要拆我的泵，我就让你尝尝没有泵是什么滋味！” |
| 打坏一台泵 | “那是 C 泵……我修了三个星期。” |
| 败北 | “泵……今晚谁去开？” |
| 零第二次以后打败他 | “你又来了。说真的，你要是不打我，我能请你吃碗面。” |

### 战后

1. 汉克从机甲里爬出来，坐在排水渠边上。墙上的涂鸦“汉克修好了 4 号泵”被闪电照亮。
2. **记忆闪回**：雨夜，小时候的零坐在屋檐下修收音机，收音机里传出一段奇怪的歌声。那是霓姬，第一次和零说话。
3. **奖励**：「泄洪」（专属重武器）和「排水王机甲外壳」（专属装甲）二选一，另一件转换成信用点。
4. **可选互动**：零可以按 E 帮汉克重启一台泵。第一次这么做时，汉克会说：“……你和她小时候一个样，爱多管闲事。”从此以后，积水区每个房间的积水面积减少 20%（汉克修好了泵）。
5. 开车转场开始，前往第 2 区。

## 十二、验收标准

完成后，用以下几条检查这一关是否达到设计目标：

1. **教学**：没玩过的人不看说明，能在第一局里自己学会闪移、换武器、骇入变电箱。
2. **核心动词**：至少一半的测试玩家会主动把敌人引进水里再通电。
3. **可读性**：雨夜、暗色调的画面里，玩家能一眼分清哪些东西能互动、哪些东西危险。
4. **时长**：首次通关积水区在 8–12 分钟之间。
5. **情感**：测试后问玩家“排水王是个什么样的人”，大部分人的回答从“恶霸”变成了“有点可怜”或者“其实是好人”。
