# NEON DRIFT 霓虹漂流

Unity 2D 像素风、俯视角动作肉鸽 RPG：一个被备份了 47 次的雇佣兵，每次死亡都在地下诊所重启，一路杀穿九层城，夺回自己的记忆。

- 结构参考《哈迪斯》（据点 → 闯关 → 死亡 → 据点）
- 操作与构筑参考《元气骑士》（四朝向移动，双武器切换）
- 美术：高清像素 + 体积光，雨夜霓虹的美式赛博朋克
