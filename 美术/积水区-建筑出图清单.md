# 积水区 · 建筑出图清单

第一关后排的房子和设施，用 Midjourney 逐张生成。画面以 `images/关卡01/概念图_积水区_基准.png` 为准。

## 出图设置

- **风格参考**：每次都用同一张概念图，权重中等。不要设成图像提示，否则会画成一整片街区。
- **比例**：按每条标注选。
- **每条出 4 张，挑一张**：底边平、图里没有雨、像素清楚。
- **招牌不让 Midjourney 画字**：它写中文基本是乱码。招牌在 Unity 里用像素字单独做成霓虹，下面每栋都写了招牌内容。
- **占几格**：处理图片时按下表设置，正面沿墙线占的格数。

## 招牌的状态说明

| 状态 | 游戏里的做法 |
| --- | --- |
| 完整 / 常亮 | 一直亮 |
| 某个字坏了 | 那个字不亮，其余正常 |
| 忽明忽暗 / 闪烁 | 随机闪，频率不一样 |
| 不发光 | 喷漆、手写、贴纸，只是贴图 |

整条街只有回声诊所的招牌是完整的，其余的或多或少都坏了一点，这是美术基调里定下的。
